# T-shirts Store

## Descripción del Proyecto

Este proyecto es un sitio web estático desarrollado en HTML para una tienda online de camisetas. El sitio presenta una interfaz sencilla y atractiva que permite a los usuarios explorar una colección exclusiva de camisetas.

## Contexto

**T-shirts Store** es una página web diseñada como tienda de camisetas en línea que ofrece:

- **Catálogo de Productos**: Visualización de camisetas con imágenes, descripciones y precios
- **Navegación Intuitiva**: Menú con acceso a diferentes secciones (Home, Products, Services, Contact)
- **Próximos Lanzamientos**: Sección dedicada a anunciar nuevos productos y ofertas especiales
- **Diseño Responsive**: Adaptado para diferentes dispositivos mediante meta viewport

### Características Principales

- Página de bienvenida con presentación de la tienda
- Catálogo de productos mostrando:
  - Camiseta Blanca Clásica ($19.99)
  - Camiseta Negra Clásica ($20.99)
- Sección de "Próximamente" anunciando:
  - Camisetas con gráficos
  - Camisetas con cuello en V
  - Camisetas de manga larga
  - Camisetas personalizables
- Integración de fuentes de Google Fonts (Roboto y Bitcount Grid Single)

## Tecnologías Utilizadas

- HTML5
- Fuentes de Google (Roboto, Bitcount Grid Single)
- Imágenes hospedadas en web

## Cómo Iniciar el Servidor

Para visualizar el sitio web en tu navegador local, puedes usar la extensión **Live Server** de Visual Studio Code.

### Instalación de Live Server

1. Abre Visual Studio Code
2. Ve a la sección de Extensiones (ícono de cuadrados en la barra lateral o `Ctrl+Shift+X` / `Cmd+Shift+X`)
3. Busca "Live Server" (autor: Ritwick Dey)
4. Haz clic en "Instalar"

### Iniciar el Servidor

Existen dos formas de iniciar Live Server:

**Opción 1: Desde el archivo HTML**
1. Abre el archivo `index.html` en Visual Studio Code
2. Haz clic derecho en el editor
3. Selecciona "Open with Live Server"

**Opción 2: Desde la barra de estado**
1. Abre el archivo `index.html` en Visual Studio Code
2. En la esquina inferior derecha, haz clic en el botón "Go Live"

El servidor se iniciará automáticamente y abrirá el sitio en tu navegador predeterminado, típicamente en la dirección `http://127.0.0.1:5500/index.html`

### Detener el Servidor

Para detener Live Server:
- Haz clic en el botón "Port: 5500" en la barra de estado inferior
- O cierra Visual Studio Code
